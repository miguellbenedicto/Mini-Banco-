# 💰 MiniBanco
 
Um sistema bancário simples desenvolvido em **Java** para execução via console (terminal). 

O projeto simula operações essenciais de uma conta bancária de forma interativa, aplicando conceitos fundamentais de lógica de programação, modularização por métodos e estruturas de controle.
 
## 🚀 Funcionalidades
 
- **Identificação do Cliente:** Boas-vindas personalizada ao iniciar o sistema.

- **Depósitos:** Adição de valores ao saldo com validação de montantes positivos.

- **Saques com Taxa:** Realização de saques aplicando uma taxa percentual fixa, com validações para:

  - Valores válidos (maiores que zero).

  - Limite máximo permitido por operação.

  - Verificação de saldo suficiente (incluindo o valor da taxa).

- **Consulta de Saldo:** Visualização rápida do saldo atualizado da conta.

- **Extrato Detalhado:** Histórico de todas as movimentações realizadas durante a sessão.
 
## 🛠️ Tecnologias Utilizadas
